ATELIER — Premium Website Experience Library
=============================================
1. Extract ALL parts into the SAME folder (they merge into one "atelier" tree).
2. cd atelier && npm install && npm run dev
3. Open the URL Vite prints (usually http://localhost:5173)

Parts:
  atelier-1-app.zip      — platform shell, code, platform imagery
  atelier-2-coffee.zip   — 10 coffee templates + images + videos (designs 01–05)
  atelier-3-videos.zip   — videos for coffee designs 06–10
  atelier-4-jewelry.zip  — 10 jewelry website templates
  atelier-5-zips-a.zip   — standalone project zips, coffee designs 01–05
  atelier-6-zips-b.zip   — standalone project zips, coffee designs 06–10

Each standalone zip is an independent Vite project: npm install && npm run dev.
